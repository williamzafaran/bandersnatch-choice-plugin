🎬 Bandersnatch Interactive

Interactive choice overlay for Black Mirror: Bandersnatch. Injects Netflix-style choice buttons directly into the native Jellyfin player.

General

When disabled, the plugin is fully passive — no overlays, no seek prompts.

Choice Overlay Timing

How many seconds before the segment ends to show the choice buttons. Netflix uses ~10 seconds. Default: 10.

Item Detection

Automatically identifies Bandersnatch by matching the item title (contains "Bandersnatch") and duration (~5h 12m). Only activates for the full interactive cut — not the standard 90-minute version.
If auto-detection picks the wrong item (or you have a non-standard filename), paste your Bandersnatch Item ID here. Find it in the Jellyfin URL when browsing the item: ?id=<ItemId>. Leave blank to rely on auto-detection.
