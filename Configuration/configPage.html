🎬 Bandersnatch Interactive

Interactive choice overlay for Black Mirror: Bandersnatch. Injects Netflix-style choice buttons directly into the native Jellyfin player.

General

When disabled, the plugin is fully passive — no overlays, no seek prompts.

Choice Overlay Timing

How many seconds before the segment ends to show choice buttons. Netflix uses ~10 seconds. Default: 10.

Item Detection

Matches by title (contains "Bandersnatch") and duration (~5h 12m). Only activates for the full interactive cut.
Auto-filled if Bandersnatch is detected. Paste your Item ID here if detection fails — find it in the Jellyfin URL: ?id=<ItemId>.

Chapter Markers

Writes all 250 Bandersnatch segment timestamps as Jellyfin chapter markers on the item. Lets you see segment boundaries in the seekbar and jump between them. Save settings first if you just changed the Item ID.
